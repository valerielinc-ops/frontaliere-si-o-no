# Instagram Story concepts

The current automated Story path republishes the post's rendered cover as
one static image through Meta's Graph API. That cover already contains the
publisher-verified topic and the Codex-generated hook selected for the feed
post. The flow has no separate Story copy-pack slot and does not create polls,
question boxes, quizzes, link stickers, or other interactive elements.

When asked for a concept, give a short sequence of plain-text frames using
only a verified article, job, or border source supplied with the request.
Keep one idea per frame, put any factual qualification beside its claim, and
end only with a destination or action the current publisher can fulfill. Do
not promise DMs, sticker interactions, personal answers, or a follow-up asset.

For the automated weekly copy pack, use this skill to keep the reusable
feed hook legible and accurate when the publisher reuses the rendered cover as
a single Story frame. Do not add a separate Story template, promise sticker
interactions, or describe Story-specific attribution that the current publisher
and measurement contract do not record.
