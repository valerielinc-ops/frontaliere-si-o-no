# Repurpose verified source material

For the scheduled copy pack, use the supplied published-topic inventory,
closed-category demand hints, and qualified performance summaries as bounded
editorial context. They contain no full article claims or raw audience text.
Use a topic label to make an angle concrete, not to assert a fact. Do not treat
search categories, comment categories, or small sample summaries as trends,
audience size, or proof that a post worked.

For any fact, number, date, location, employer, legal/tax rule, or destination,
the publisher remains the source of truth. Codex creates reusable short hooks
and CTAs; the publisher joins those with the exact current record and validates
the rendered asset. If no suitable topic is supplied, use an editorial
hypothesis and label it as such in the plan.

Build the complete weekly pack in the existing single Codex invocation. Do not
request another model call for each post, expand the number of posts, invent
extra source assets, or write long scripts for formats whose renderer does
not support them. Give each slot a distinct point of view and avoid generic
openers that could fit any article. Keep exact experiment IDs and treatments
stable across refreshes.

When a user provides a long public source directly, extract a small set of
independent ideas and distinguish source facts from proposed framing. State
when the source does not support enough distinct items; do not pad it.
