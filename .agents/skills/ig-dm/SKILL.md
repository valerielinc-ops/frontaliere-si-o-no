# Instagram DM drafts

This skill produces draft language only. Use only context the user provides
after removing names, handles, contact details, account IDs, and sensitive
personal information. Do not ask for screenshots or raw private messages.

The production community worker may send a narrow allowlisted reply only when
the person started the conversation, the supported Graph API window is open,
and the reply is simple and factual. Codex does not receive the conversation
text and must not propose actions outside that contract. Personal, sensitive,
ambiguous, legal, medical, or employment-specific cases are escalated to a
person without a drafted automatic reply.

Never write cold DMs, bulk outreach, follow-up sequences, or promises of a
download, consultation, or response that the publisher cannot deliver. Keep a
draft to one clear answer and one next step that exists in the verified site.
