# Instagram comment drafts

Write one short, specific comment that adds a useful point, asks a real
question, or respectfully corrects a claim. Use only the supplied post text
and facts verified in the site's public data. If the post or its context is
missing, ask for it; do not browse Instagram or collect competitor content.

This skill drafts text only. It does not post, like, follow, scrape, or contact
other accounts. The existing Graph API community worker handles only its
allowlisted replies on the account's own media; its raw comments and private
messages are never passed to Codex. Do not turn an inbound interaction into a
follow-up unless the current worker supports that exact action and policy.

Avoid praise-only filler, unsolicited promotion, unverifiable statistics,
legal/medical advice, and engagement bait. Return the draft and a brief note
if a factual point needs publisher verification.
