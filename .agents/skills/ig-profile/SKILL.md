# Instagram profile review

Review only text, screenshots, or public facts supplied by the user. Do not
log in, inspect private account pages, change profile settings, or claim that
an edit will increase reach or ranking. The project has no approved profile
editing integration.

Use `rubric.json` to organize observations about the name, bio, link,
highlights, pinned posts, and first-view grid. Treat scores as prioritization
heuristics rather than measured Instagram outcomes. Separate verified site
facts from copy suggestions and never invent services, credentials, results,
or posting frequency.

Return the highest-impact edits first, with ready-to-paste alternatives. The
account owner applies any changes through Instagram's supported interface.
