  • Starke nachgewiesene Erfolgsbilanz der relevanten Software-Entwicklungserfahrung von mindestens 3 Jahren
  • Gutes Wissen und fundiertes Verständnis von Datenbanktechnologien (SQL, Oracle PL/SQL)
